# Auto Valley

Society: Sunlit Valley용 **클라이언트 전용** 농장 보조 모드입니다. Minecraft **1.20.1**, Forge **47.4.0**, Society **4.1.4**의 설치된 동작을 기준으로 개발했습니다. 내 클라이언트에 설치하며 서버 설치는 필요하지 않습니다.

## 시작

1. [Releases](https://github.com/Schwalbe262/auto_minecraft/releases)에서 `autovalley-0.1.0.jar`를 받아 해당 CurseForge 인스턴스의 `mods` 폴더에 넣고 게임을 재시작합니다.
2. 서버에 접속한 뒤 **Ctrl+F8**로 설정을 엽니다. 처음 접속하거나 재접속하면 항상 전체 OFF입니다.
3. 아래 초기 등록을 마치고 화면을 닫은 뒤 **F8**로 시작합니다. **Pause**는 긴급 정지입니다.

다른 창으로 전환하거나 직접 게임을 조작하면 일시정지합니다. 다시 시작하려면 F8을 누르세요. 키는 Minecraft 조작 설정의 Auto Valley 항목에서 바꿀 수 있습니다. 경유지 등록 키는 기본 미지정이며, 필요하면 직접 지정하세요.

## 초기 등록

- **괭이:** 사용할 괭이를 핫바에서 선택하고 설정의 괭이 등록을 누릅니다.
- **주변 후보:** 등록 탭에서 탐색합니다. 주변 로드된 블록만 탐색하므로 다른 장소는 직접 이동한 뒤 다시 탐색하세요.
- **밭 두 구역:** 토마토를 바라본 뒤 설정을 열어 첫 모서리와 두 번째 모서리를 지정합니다. 줄 위의 토마토까지 들어가도록 위아래 높이를 포함하세요. 자동 제안 영역도 확인 후 저장해야 합니다.
- **창고:** 토마토는 등급 0(일반), 1(철), 2(금), 3(다이아몬드)별로 등록합니다. 와인은 아이템의 **생산연도 `Year`**별로 등록합니다. 각 상자의 내용물을 열어 확인한 뒤 등록하세요. 한 상자에는 한 분류를 지정합니다. 큰 상자는 양쪽을 하나로 취급합니다.
- **설비:** 와인통, 절임통, 스마트 배송상자와 침대를 각각 등록합니다.
- **폐기:** 썩은 토마토가 안전하게 떨어질 곳을 바라보고, 서 있는 위치와 방향을 등록합니다. 바닥 투척 방식이므로 수거 자석이나 다시 주워지는 장소를 피하세요.
- **이동 경로:** 밭과 지하 창고 사이의 통로·계단·모퉁이에서 순서대로 경유지를 등록합니다. 등록된 작업 구역과 연결 통로 안에서만 이동합니다. 블록 파괴나 점프가 필요한 길은 사용할 수 없습니다.

등록 후에는 먼저 기능 하나씩 켜서 경로와 분류를 확인하세요. F8 재개는 현재 위치·상자·인벤토리를 다시 확인합니다. 상자 안에서 중지했다면 직접 상태를 확인하고 닫은 뒤 재개하세요.

## 자동화 동작

| 기능 | 기준 |
|---|---|
| 수확 | 괭이를 들고 익은 `tomatoes` / `tomatoes_on_rope`만 우클릭, 두 구역과 누락 작물 재확인 |
| 폐기 | 등록 위치·방향에서 `farmersdelight:rotten_tomato`만 투척 |
| 토마토 보관 | 아이템의 `quality_food.quality`로 등급 분류 |
| 생산 재료 | 등록 창고와 소지품의 등급별 총수량을 집계하고 가장 많은 등급부터 사용; 동률은 낮은 등급 우선 |
| 와인 | 먼저 재료 배정, 3개씩 투입, 완성품 수거 후 생산연도별 보관 |
| 병조림 | 와인에 배정하고 남은 토마토 사용; 기본 5개, 업그레이드 통은 3개 |
| 배송 | 토마토 병조림만 스마트 배송상자 입력으로 이동 |
| 수면 | 할 수 있는 활성 작업을 마친 뒤 게임 시간 18:35부터 시도; 실제 다음 날 전환 확인 |

### 날짜 단위 쿨타임

실시간 초가 아니라 **게임 날짜**로 다음 예정일을 저장합니다. 와인 기본 주기는 **6일**, 절임통은 **3일**입니다. 토마토 기본 **1일은 상태 확인 간격**이며, 하루마다 반드시 다시 익는다는 뜻이 아닙니다. 일반 토마토는 성장 단계와 비료에 따라 실제 수확 간격이 달라집니다. 확인한 밭의 주기에 맞춰 설정에서 1~28일로 조절하세요.

예정일 전에는 해당 작업을 건너뜁니다. 예정일에도 실제 성장·완료 상태를 확인하며 미완성 설비를 무작정 클릭하지 않습니다. 새날의 성장·설비 갱신 시간을 기다린 뒤 판단합니다. 일정은 재접속 후에도 유지됩니다. 직접 설비를 다시 채우거나 구조를 바꿨다면 설정의 **일정 초기화**로 다시 관찰하게 할 수 있습니다.

### 빠른 수확

설정에서 속도 측정을 준비한 뒤 닫고 F8로 시작합니다. 실제 이동이 있는 걷기 4회와 달리기 4회를 비교하고, 확인된 수확과 획득 결과가 정상일 때만 더 빠른 모드를 적용합니다. 측정할 익은 작물이 부족하면 다음 수확까지 이어집니다. 농지 위로 점프하지 않습니다.

## 중지 조건과 현재 범위

공격·블록 파괴는 자동화 API에 없으며, 실행 중 해당 입력과 패킷도 차단합니다. 인벤토리 이동은 서버의 전체 상태 응답을 확인한 뒤 이어갑니다. 응답이 불분명한 생산 조작은 자동 재실행하지 않습니다.

저장 공간 부족, 미등록 와인 연도, 접근할 수 없는 경로, 낮은 체력·허기, 도구 문제는 상태 표시와 함께 중지 또는 대기합니다. 먹기·수리·전투·건축·텔레포트는 포함하지 않습니다. 서버의 수면 조건이나 다른 플레이어의 상태 때문에 하루가 넘어가지 않을 수 있습니다.

이 릴리스는 빌드·자동 테스트를 통과한 초기 버전입니다. 실제 사용자의 서버에서 위치 등록, 생산 주기, 수거 자석과 배송 동작은 첫 실행 때 확인해야 합니다. 다른 모드팩 버전이나 서버 설정은 동작이 다를 수 있습니다.

## 빌드와 설치 도구

JDK 17을 지정한 뒤 실행합니다. Gradle 8.8과 ForgeGradle 6.0.54를 사용합니다.

```powershell
.\gradlew.bat test build
.\scripts\Install-Mod.ps1 -InstancePath 'C:\path\to\Society Sunlit Valley'
```

설치 스크립트는 인스턴스 버전을 확인하고 기존 Auto Valley JAR만 백업합니다. 실행 중인 게임을 종료하지 않으며, 새 파일은 다음 재시작에 로드됩니다. 제거하려면 게임 종료 후 `mods`의 `autovalley-*.jar`만 다른 폴더로 옮기세요.

설정은 인스턴스의 `config/autovalley/`에 서버·차원·플레이어별 해시 파일명으로 저장됩니다. 이전 설정의 `.bak` 파일을 유지합니다. 서버 주소, 개인 좌표, 월드 데이터는 이 저장소에 포함하지 않습니다.

구조와 검증 사항은 [개발 문서](docs/ARCHITECTURE.md)를 참고하세요.
