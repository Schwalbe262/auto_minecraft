# 확인된 와인 재료 부족의 반복 재조사 방지

## 실제 관측

최종 벌목 중단 복구를 적용한 뒤 장시간 관측 중 별도 문제가 발견됐다.
고대과일 와인은 재료가 없어 63통이 남았는데도 1,200틱마다 설비/창고로
재진입했다. 같은 보류 결과가 스케줄 순회마다 다시 오류 이력에 기록되기도 했다.
따라서 오류 횟수 증가를 실제 왕복 횟수로 해석하면 안 된다.

12:59:47 같은 게임 날짜 767, 보유 과일 0 상태로 재조사했고 13:01:07에도
설비 이동이 재개됐다. 반면 13:00:35–13:00:50에는 위치·인벤토리가 같은데
보류 횟수가 7에서 14로 늘었다. 자동화 전체가 꺼진 사건은 아니지만,
불필요한 재방문과 반복 경고를 줄이기 위해 보완했다.

## 동작

- 등록된 출처 전체를 현재 날짜에 안전하게 확인한 실제 입력 부족만 별도
  대기로 분류한다. 오류 문구의 문자열 일치로 분류하지 않는다.
- 연속 모드는 같은 날 확인된 재료 부족을 정상 대기로 유지한다. 남은 설비나
  생산 일정을 완료 처리하지 않으며, 같은 재고를 1분마다 다시 조사하지 않는다.
- 다음 게임 날짜, 관련 설정/출처/권한 변경, 인벤토리에 사용할 수 있는 같은
  등급 재료가 생긴 경우 기존 안전 검사부터 다시 진행한다.
- 원샷 부족은 계속 미완료로 보고한다. 명시적인 F8 재시작은 재조사를 허용한다.
- 같은 날 상자에만 외부에서 보충한 경우는 다음 게임 날짜 또는 F8 재시작 전까지
  자동으로 알 수 없다. 인벤토리의 새 재료는 최대 100틱 스케줄 확인 후 재평가한다.
- 다른 라인의 자동 이동 재시도가 발생해도 검증된 재료 부족 관측만 유지한다.
  진행 중 조작·일반 실패·메뉴 상태는 기존대로 초기화한다. 수동 시작/중지는
  여전히 전체 초기화를 수행한다.
- 조사가 자정을 넘으면 이전 날짜의 빈 재고를 새 날짜의 확정값으로 사용하지
  않고 다시 확인한다. 단축바 반환·미확인 산출물·네이티브 응답 경계는 우회하지 않는다.

## 검증 범위

실제 전체 출처 조사, 같은 날 5,000틱 무재방문, 다른 와인/취침 계속 실행,
새 재료·날짜·설정 변화, 원샷/F8, 일반 실패와의 구분, 단축바/네이티브 의무,
자정 경계 및 다른 라인의 자동 재시도와의 조합을 회귀 테스트에 포함했다.
전체 빌드 및 적용 후 장시간 검증 결과는 확인 후 추가한다.

전체 `test build` 통과: 2,627개, 실패·오류·건너뜀 0개.
이번 보완으로 회귀 테스트 15개가 추가됐다.
JAR SHA256: `CD84BBF640087F653D30590A803C59E32A0583424916F095000147E9C1542936`.
아래 적용 기록 이후 최소 2시간 안정화 관측을 진행 중이다.

13:20:23 기존 벌목·보관이 끝난 깨끗한 대기 상태에서 정상 일시정지 후 종료했다.
이전 JAR는 백업하고 같은 Society 인스턴스에 위 해시의 JAR를 설치했다.
13:22:34 정상 서버 연결에서 연속 시작이 승인됐고, 이 시점 이후를 최종 버전의
최소 2시간 관측 대상으로 삼는다. 앞선 약 38분의 예비 관측은 이 시간을 대체하지 않는다.

### 첫 10분 및 다음 날 재개 관측

13:22:40–13:32:41 KST의 39개 표본은 모두 최신·접속·연속 실행 상태였고,
오류 이력은 비어 있었다. 확인된 재료 부족 대기가 12개 표본에 나타났으며
남은 63통이 유지됐다. 같은 날짜 770에 재료 창고로 반복 왕복하는 현상은
관측되지 않았다. 절임통 144개의 다음 작업일이 773으로 갱신되고 보관도 진행됐다.

벌목은 13:27:28에 남은 구역 6곳으로 시작했고 13:28:15에 3곳이 남았다.
여기서 3은 전체 등록 수가 아니라 진행 중 남은 작업 수다. 실제 설정에는
6곳이 모두 등록돼 있다. 13:29:03에는 남은 벌목·재식재가 0이 됐지만 후처리는
진행 중이었으며, 13:29:34 표본에서 배치 종료·단축바 반환 의무 없음·다음 예정일
771을 함께 확인했다. 통나무 증가, 가공품 전환, 보관 및 베리 배송 상태도 관측됐다.
인벤토리 감소만으로 개별 판매량이나 금액을 확정하지 않는다.

이후 취침해 13:33:28 표본에서 게임 날짜 771 및 다음 날 와인 상태 확인을
관측했다. 관측 간격은 약 15–17초이므로 매 틱의 실행을 증명하는 것은 아니며,
이 첫 완료 및 10분 결과는 최소 2시간 장기 검증을 대체하지 않는다.
