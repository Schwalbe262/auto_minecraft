# 확인된 와인 재료 부족의 반복 재조사 방지

## 실제 관측

최종 벌목 중단 복구를 적용한 뒤 장시간 관측 중 별도 문제가 발견됐다.
고대과일 와인은 재료가 없어 63통이 남았는데도 1,200틱마다 설비/창고로
재진입했다. 같은 보류 결과가 스케줄 순회마다 다시 오류 이력에 기록되기도 했다.
따라서 오류 횟수 증가를 실제 왕복 횟수로 해석하면 안 된다.

12:59:47 같은 게임 날짜 767, 보유 과일 0 상태로 재조사했고 13:01:07에도
설비 이동이 재개됐다. 반면 13:00:35–13:00:50에는 위치·인벤토리가 같은데
보류 횟수가 7에서 14로 늘었다. 자동화 전체가 꺼진 사건은 아니지만,
불필요한 재방문과 반복 경고를 줄이기 위해 보완했다.

## 동작

- 등록된 출처 전체를 현재 날짜에 안전하게 확인한 실제 입력 부족만 별도
  대기로 분류한다. 오류 문구의 문자열 일치로 분류하지 않는다.
- 연속 모드는 같은 날 확인된 재료 부족을 정상 대기로 유지한다. 남은 설비나
  생산 일정을 완료 처리하지 않으며, 같은 재고를 1분마다 다시 조사하지 않는다.
- 다음 게임 날짜, 관련 설정/출처/권한 변경, 인벤토리에 사용할 수 있는 같은
  등급 재료가 생긴 경우 기존 안전 검사부터 다시 진행한다.
- 원샷 부족은 계속 미완료로 보고한다. 명시적인 F8 재시작은 재조사를 허용한다.
- 같은 날 상자에만 외부에서 보충한 경우는 다음 게임 날짜 또는 F8 재시작 전까지
  자동으로 알 수 없다. 인벤토리의 새 재료는 최대 100틱 스케줄 확인 후 재평가한다.
- 다른 라인의 자동 이동 재시도가 발생해도 검증된 재료 부족 관측만 유지한다.
  진행 중 조작·일반 실패·메뉴 상태는 기존대로 초기화한다. 수동 시작/중지는
  여전히 전체 초기화를 수행한다.
- 조사가 자정을 넘으면 이전 날짜의 빈 재고를 새 날짜의 확정값으로 사용하지
  않고 다시 확인한다. 단축바 반환·미확인 산출물·네이티브 응답 경계는 우회하지 않는다.
