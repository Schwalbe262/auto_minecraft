[진단 파일 읽기 경합 기록](STABILITY-INSPECTION-IO-20260912.md)에 정리했다.
이전 구간의 시간·완료 횟수를 새 구간에 더해 연속 통과로 만들지 않는다.

`HARVEST / BLOCKED / tick 17506 / occurrences 1`은 새 구간 첫 표본부터
존재한 과거 이력이다. 14:59:48까지 같은 값으로 유지됐다. 따라서
“새 실패 0건”은 “과거에도 실패가 없었다”는 뜻이 아니다. 이후 보관 재방문과
